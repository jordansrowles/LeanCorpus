### Added

- Community Server 0.1.0-alpha with transport-neutral contracts, local lifecycle and persistence, schema-authoritative writes, search, explain and bounded inspection
- Reusable ASP.NET Core and typed gRPC adapters, plus the `Rowles.LeanCorpus.Server.Local` reference host
- Version-one Community OpenAPI and typed protobuf contract artefacts, Community DI defaults and replaceable authentication, authorisation, routing, consistency and audit ports
- Embeddable `Rowles.LeanCorpus.Studio` workflows for lifecycle, inspection, documents, queries, explanations and settings
- `./devops server start`, including explicit trusted-network access with `-External`

### Changed

- Server projects are part of the normal solution and DevOps test-suite mappings
- Local registry state is versioned and validated, with opaque physical index identifiers and atomic persistence
- Bulk writes now enforce configured limits, schema types, refresh semantics and bounded local idempotency
- Graceful shutdown stops new operations, drains active work for a bounded period and commits owned index runtimes
- Server integration coverage exercises REST, gRPC, Studio and restart persistence on .NET 11

### Compatibility

- Community Server product version: 0.1.0-alpha
- REST API: v1
- gRPC API: v1
- Registry format: 1
- Community topology is single-node with one shard and zero replicas
