### Added

- Community Server 0.1.0-alpha.1 as a transport-neutral, local single-node HTTP and gRPC server over the LeanCorpus engine
- Explicit logical-index registration with opaque physical storage IDs, persisted schema and restart recovery
- Local bulk indexing with independent Memory or LocalFsync durability, refresh control, idempotency replay and version-one write/read tokens
- Deterministic score and field sorting with validated search-after cursors and an _id tie-break
- Health and readiness state for local commit, installation and runtime failures
- Atomic committed snapshot installation and a two-copy filesystem acceptance suite covering cancellation, corruption, stale generations and promotion
- Reusable Server.Core, ASP.NET Core and typed gRPC adapters, plus the embeddable Community Studio at /studio
- Linux and Windows CI coverage for Server abstractions, Core and transport integration suites

### Changed

- Server package and telemetry product versions now identify 0.1.0-alpha.1
- REST JSON uses the same named durability, consistency, token and query-kind contract values documented by OpenAPI and protobuf
- Unsupported Community capabilities return stable typed failures, including durability_not_supported, consistency_unavailable, inspection_not_supported and explain_not_supported
- Community OpenAPI lists only Community routes and records the supported Terms facet subset and cursor/query shapes
- Server test projects now live under `src/server/devops`, with solution, DevOps suite and CI paths aligned

### Security

- Destructive index deletion requires a server-side confirmation token
- The reference host binds to loopback by default; -External is an explicit trusted-network listener without authentication or TLS
- Request bodies, documents, bulk operations, queries, inspection output and retained idempotency entries remain bounded by configuration

### Compatibility

- Community Server product version: 0.1.0-alpha.1 and currently unreleased; alpha APIs may change before publication
- Server.Core consumes LeanCorpus 3.1.0 APIs added for commit metadata, cancellable snapshot transfer and stable typed search-after values
- Server packages target .NET 11
- REST API: v1
- gRPC API: v1
- OpenAPI and protobuf contract artefacts are version one
- Registry format: 1
- Community topology is single-node with one shard and zero replicas
- Community does not provide clustering, replication, quorum durability, licensing, account management or external-service integration
