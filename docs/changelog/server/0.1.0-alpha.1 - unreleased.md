# Community Server 0.1.0-alpha.1: unreleased

- Optional Orchard Core search provider package with content indexing, generic search, native queries, a handler-emitted vector KNN probe, task-cursor recovery coverage, and paired Lucene comparison evidence.
- Community Server 0.1.0-alpha.1 as a transport-neutral, local single-node HTTP and gRPC server over the LeanCorpus engine. ([75c5f7c5b](https://github.com/jordansrowles/LeanCorpus/commit/75c5f7c5bc37e7bc0b465da9159b5134d3062acf), [5cf080e11](https://github.com/jordansrowles/LeanCorpus/commit/5cf080e113150057b253654c65c8bce3ad5ac883))
- Explicit logical-index registration with opaque physical storage IDs, persisted schema and restart recovery. ([75c5f7c5b](https://github.com/jordansrowles/LeanCorpus/commit/75c5f7c5bc37e7bc0b465da9159b5134d3062acf), [5cf080e11](https://github.com/jordansrowles/LeanCorpus/commit/5cf080e113150057b253654c65c8bce3ad5ac883))
- Local bulk indexing with independent Memory or LocalFsync durability, refresh control, idempotency replay and version-one write/read tokens. ([75c5f7c5b](https://github.com/jordansrowles/LeanCorpus/commit/75c5f7c5bc37e7bc0b465da9159b5134d3062acf), [5cf080e11](https://github.com/jordansrowles/LeanCorpus/commit/5cf080e113150057b253654c65c8bce3ad5ac883))
- Deterministic score and field sorting with validated search-after cursors and an `_id` tie-break. ([1e8e4646b](https://github.com/jordansrowles/LeanCorpus/commit/1e8e4646bf4e00f6cfdb969b0704578c46c5ad73))
- Health and readiness state for local commit, installation and runtime failures. ([75c5f7c5b](https://github.com/jordansrowles/LeanCorpus/commit/75c5f7c5bc37e7bc0b465da9159b5134d3062acf), [5cf080e11](https://github.com/jordansrowles/LeanCorpus/commit/5cf080e113150057b253654c65c8bce3ad5ac883))
- Atomic committed snapshot installation with cancellation, corruption and stale-generation checks. ([75c5f7c5b](https://github.com/jordansrowles/LeanCorpus/commit/75c5f7c5bc37e7bc0b465da9159b5134d3062acf), [5cf080e11](https://github.com/jordansrowles/LeanCorpus/commit/5cf080e113150057b253654c65c8bce3ad5ac883))
- Reusable Server.Core, ASP.NET Core and typed gRPC adapters, plus the embeddable Community Studio at `/studio`. ([1e8e4646b](https://github.com/jordansrowles/LeanCorpus/commit/1e8e4646bf4e00f6cfdb969b0704578c46c5ad73))

## Changed

- Target .NET 10 and .NET 11 throughout the Community Server and Orchard host dependency graphs and register both frameworks for tests, strict package archive checks and published-package consumer validation. `devops server start -Framework` selects the reference-host runtime; .NET 10 offers Brotli/gzip response compression and .NET 11 retains zstd.
- Process each Orchard document batch through LeanCorpus' ordered multi-document replacement API, applying deletes before replacements and avoiding repeated per-document flushes during task replay.
- Query-string translation now uses the analyser configured for each explicitly selected text field. ([f03538876](https://github.com/jordansrowles/LeanCorpus/commit/f035388760fa914e334139962cc288debbf72f76))
- Server projects now use the platform default runtime execution features rather than forcing Runtime Async. ([baa02a9fe](https://github.com/jordansrowles/LeanCorpus/commit/baa02a9fe652024ade2bf5f5639a84371ab60c33))
- Server package and telemetry product versions now identify 0.1.0-alpha.1. ([75c5f7c5b](https://github.com/jordansrowles/LeanCorpus/commit/75c5f7c5bc37e7bc0b465da9159b5134d3062acf), [5cf080e11](https://github.com/jordansrowles/LeanCorpus/commit/5cf080e113150057b253654c65c8bce3ad5ac883))
- REST JSON uses the same named durability, consistency, token and query-kind contract values documented by OpenAPI and protobuf. ([75c5f7c5b](https://github.com/jordansrowles/LeanCorpus/commit/75c5f7c5bc37e7bc0b465da9159b5134d3062acf), [5cf080e11](https://github.com/jordansrowles/LeanCorpus/commit/5cf080e113150057b253654c65c8bce3ad5ac883))
- Unsupported Community capabilities return stable typed failures, including durability_not_supported, consistency_unavailable, inspection_not_supported and explain_not_supported. ([75c5f7c5b](https://github.com/jordansrowles/LeanCorpus/commit/75c5f7c5bc37e7bc0b465da9159b5134d3062acf), [5cf080e11](https://github.com/jordansrowles/LeanCorpus/commit/5cf080e113150057b253654c65c8bce3ad5ac883))
- Community OpenAPI lists only Community routes and records the supported Terms facet subset and cursor/query shapes. ([75c5f7c5b](https://github.com/jordansrowles/LeanCorpus/commit/75c5f7c5bc37e7bc0b465da9159b5134d3062acf), [5cf080e11](https://github.com/jordansrowles/LeanCorpus/commit/5cf080e113150057b253654c65c8bce3ad5ac883))

## Fixed

- Publish local durability receipts in physical commit order, keep waiter state monotonic, and record observer failures separately from physical commit failures.
- Carry an admitted physical-operation lease through Server and Orchard commit/refresh stages, and reject cross-root Orchard ownership of an active tenant path.
- Reopen a caller-disposed Server handle only after its successful close; remove a newly created index directory when initial handle construction fails and cleanup succeeds.

- Keep snapshot file streams and active backups pinned through physical shutdown, and reject new snapshot reads after their parent lease is disposed.

- Release previously opened indexes when Server registry startup fails, report active snapshot leases, propagate engine fault/refresh health, and resolve fatal durability waiters without claiming failed refreshes are visible.

- Release Orchard physical indexes at terminal application shutdown even when a historical tenant shell scope remains retained, and share Core searcher-generation and lease management.
- Close admission on a disposed physical store, attempt cleanup for every index when one close fails, and preserve the shared close failure for repeated callers.
- Retain Server physical ownership and report a timeout when admitted requests have not drained; allow disposal to finish after those requests complete.
- Drain Server search leases, commit snapshots and executing commit timers before physical close, reject queued work after shutdown begins, and fail durability waiters when their coordinator closes.
- Register tenant-local provider naming for native Orchard stored-query execution.
- Use one bulk `AddDocuments` call for verified append-only writes to non-empty Server Core indexes, avoiding per-document segment creation. ([f03538876](https://github.com/jordansrowles/LeanCorpus/commit/f035388760fa914e334139962cc288debbf72f76))
- Batch Server Core replacements by applying ID deletions once before ordered additions, and preserve pinned snapshots with deletion-generation statistics sidecars. ([f03538876](https://github.com/jordansrowles/LeanCorpus/commit/f035388760fa914e334139962cc288debbf72f76))

## Security

- Apply schema and query complexity limits to query-string requests before executable query construction. ([f03538876](https://github.com/jordansrowles/LeanCorpus/commit/f035388760fa914e334139962cc288debbf72f76))
- Destructive index deletion requires a server-side confirmation token. ([1e8e4646b](https://github.com/jordansrowles/LeanCorpus/commit/1e8e4646bf4e00f6cfdb969b0704578c46c5ad73))
- The reference host binds to loopback by default; `-External` is an explicit trusted-network listener without authentication or TLS. ([75c5f7c5b](https://github.com/jordansrowles/LeanCorpus/commit/75c5f7c5bc37e7bc0b465da9159b5134d3062acf), [5cf080e11](https://github.com/jordansrowles/LeanCorpus/commit/5cf080e113150057b253654c65c8bce3ad5ac883))
- Request bodies, documents, bulk operations, queries, inspection output and retained idempotency entries remain bounded by configuration. ([75c5f7c5b](https://github.com/jordansrowles/LeanCorpus/commit/75c5f7c5bc37e7bc0b465da9159b5134d3062acf), [5cf080e11](https://github.com/jordansrowles/LeanCorpus/commit/5cf080e113150057b253654c65c8bce3ad5ac883))
- Limit wildcard and regexp patterns to 4,096 characters and each clause to 1,024 distinct matching terms by default; expose separate configuration limits and return `query_too_complex` without partial results when expansion exceeds its budget. ([af6aacfa7](https://github.com/jordansrowles/LeanCorpus/commit/af6aacfa7d1128e0f8876ab1c6d1511cb62f7c25))
