# Reference guides

Use these compact references when you need a supported API route, compatibility answer, recovery action or deployment constraint.

The generated API reference covers LeanCorpus Core, its optional compression packages and `LeanCorpus.SourceGen`. It does not list `Rowles.Text` a second time: LeanCorpus compiles the same analysis source directly, so use the Core analysis API and the [standalone package guide](../analysis/08-rowles-text.md). Community Server and Orchard packages are separate alpha tracks and are documented through the [Server guides](../server/index.md); this preview does not generate their member-level API reference.
