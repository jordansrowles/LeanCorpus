### Added

- `stored` parameter on `TextField`, `StringField`, and `NumericField` constructors (defaults to `true`, preserving existing behaviour). Reported by [@umlx5h](https://github.com/umlx5h) in #7.
- `StoredField` class for stored-only values without indexing. Added following feedback from [@umlx5h](https://github.com/umlx5h) in #7.

### Fixed

- `PrefixQuery` and `WildcardQuery` used as sub-clauses inside a `BooleanQuery` now return results correctly. The `ExecuteSubQuery` dispatch switch was missing cases for both query types, causing all intersections to silently return empty results. Reported by [@umlx5h](https://github.com/umlx5h) in #6.
- `SearcherManager` background-refresh test was susceptible to a race condition when using the default 1-second refresh interval; test now uses a 5-minute interval to keep the background loop dormant during assertions.
