# LeanCorpus DevOps 1.0.0

The managed DevOps CLI is versioned and released independently of LeanCorpus. This entry covers the managed host, its test, benchmark, coverage, diagnostics, documentation, DataForge, package and report commands, and its distributions.

## Added

- Add `./devops snowball generate`, `verify` and `fetch-data`. They generate the Snowball stemmer ports and analysis identities from pinned sources, refusing an output change without an identity change, with `generate --code-only` to write changed algorithms before the identity decision, a code hash that covers the shared runtime and a pinned fingerprint corpus; check that the committed output is current; and download the pinned French and Italian word lists after verifying their SHA-256. CI caches the word lists, runs `fetch-data` before the test and coverage suites, and runs `verify` in the Linux test job.
