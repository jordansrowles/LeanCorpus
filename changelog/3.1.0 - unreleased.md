### Added

- `LeanCorpusDefaults` provides atomically published, snapshotted process-wide defaults for newly created configurations. `IndexWriterConfig.DurableCommits` is its first override; production still defaults to durable commits. (53a1471c2)
- Foundations for richer faceted search, including bucket requests, ordering controls, missing-value handling and reliable multi-value collection (236f0e4ba, #64)
- Hierarchical `FacetPath` indexing and `HierarchicalFacetRequest` immediate-child collection through existing string postings and sorted-set DocValues (f8559fb65, #64)
- `DrillDownQuery` for exact facet selections and hierarchical path selections (f8559fb65, #64)
- `SearchWithDrillSideways` for filtered hits with selected-dimension alternatives while retaining the other active constraints (b086733b2, #64)
- Explicit double, Int64 and UTC Unix-millisecond date range facet requests with open bounds, boundary flags, document counts, missing buckets and paging (b086733b2, #64)
- UTC date histogram facets with fixed elapsed and calendar intervals, typed bucket boundaries, ISO Monday-start weeks and per-document bucket deduplication (#64)
- Commit generation and content-token metadata on `IndexWriter` and acquired `SearcherLease` instances for server-side durability and snapshot coordination (75c5f7c5b, 39e758aff)
- Typed `SearchAfterValue`, sort-value capture and explicit-value `SearchAfter` APIs for stable product-level cursor tie-breaks (39e758aff)
- Cancellation support for backup, snapshot backup and restore materialisation (39e758aff)

### Changed

- Numeric Stats aggregations now define `Count` as the number of observed numeric values, including repeated values, missing-value behaviour and explicit IEEE-754 non-finite handling (304c71795, #64)
- Advanced facet requests now apply deterministic bucket ordering, opt-in missing buckets, total-bucket metadata, offset and limit paging, while legacy facet calls remain compatible (1119d8304, #64)
- Numeric aggregations now share state-based value consumption and a merge-compatibility hook while preserving Stats and Histogram results (#64)
- Facet counts now explicitly count each matching document at most once per distinct bucket, including repeated multi-valued inputs (f8559fb65, #64)
- Functional Core tests now use an explicit non-durable default while durability tests opt in per writer. Concurrent producer commits use bounded coordination, and DWPT backpressure accounting no longer takes the writer lock while a DWPT monitor is held. (53a1471c2)
- Core test cleanup now relies on deterministic resource disposal instead of process-wide forced garbage collections, and the xUnit v3 package family is version-aligned to avoid Windows suite stalls and restore warnings. (0517a030b)
- Backup and restore cancellation is observed while manifests and files are processed, with publication remaining an indivisible final boundary (39e758aff)
- Search-after callers can provide every public sort value explicitly instead of relying on an internal document ID as the final cursor boundary (39e758aff)

### Compatibility

- This is an additive API release over 3.0.0; existing public CLR entry points, source compatibility and index-format compatibility are retained (39e758aff)
- Server packages built from the 0.1.0-alpha.1 line require LeanCorpus 3.1.0 for the new commit, cancellation and pagination APIs (5cf080e11, 61d516ff6)
