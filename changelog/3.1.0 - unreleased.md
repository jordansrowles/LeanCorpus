### Added

- Commit generation and content-token metadata on `IndexWriter` and acquired `SearcherLease` instances for server-side durability and snapshot coordination
- Typed `SearchAfterValue`, sort-value capture and explicit-value `SearchAfter` APIs for stable product-level cursor tie-breaks
- Cancellation support for backup, snapshot backup and restore materialisation

### Changed

- Backup and restore cancellation is observed while manifests and files are processed, with publication remaining an indivisible final boundary
- Search-after callers can provide every public sort value explicitly instead of relying on an internal document ID as the final cursor boundary

### Compatibility

- This is an additive API release over 3.0.0; existing source and index-format compatibility is retained
- Server packages built from the 0.1.0-alpha.1 line require LeanCorpus 3.1.0 for the new commit, cancellation and pagination APIs
