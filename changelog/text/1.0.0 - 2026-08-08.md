# Rowles.Text 1.0.0

Rowles.Text 1.0.0 is the first standalone release of the LeanCorpus analysis library. It provides the analysers, tokenisers, filters and stemmers without requiring the search engine, and was published with LeanCorpus 2.3.0. Its analysis behaviour matches the analysis that LeanCorpus 2.3.0 compiles from the same source.

### Added

- Publish LeanCorpus analysis as the standalone `Rowles.Text` package: analysers, tokenisers, token filters, stemmers and the analyser factory, with Native AOT support. ([e831990c9](https://github.com/jordansrowles/LeanCorpus/commit/e831990c912d63567217a703926fe3b0205cdd06))
- `PathTreeTokeniser` emits compound path tokens from root to leaf or leaf to root, with root-aware parsing for drive letters, UNC paths and scheme URIs, optional depth payloads and inline ASCII case normalisation. ([d5b6b1cbd](https://github.com/jordansrowles/LeanCorpus/commit/d5b6b1cbd32499ac9ec94727c590697dba5401d8))
- `ChineseLexiconTokeniser` performs greedy longest-match segmentation using built-in or file-based dictionaries. ([06aec67a6](https://github.com/jordansrowles/LeanCorpus/commit/06aec67a6b9524be443d245fcb3ee218377a6249))
- `JapaneseTokeniser` performs dictionary-backed least-cost Viterbi segmentation using a versioned and checksummed `.jlc` dictionary file. ([06aec67a6](https://github.com/jordansrowles/LeanCorpus/commit/06aec67a6b9524be443d245fcb3ee218377a6249))
